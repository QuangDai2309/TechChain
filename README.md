# Web Bán Hàng - Laravel + Vue.js + API 🛒

**Dự án web bán hàng sử dụng Laravel cho backend, Vue.js cho frontend và API để kết nối giữa chúng.**  
Ứng dụng cho phép người dùng duyệt sản phẩm, quản lý giỏ hàng và thanh toán, đồng thời admin có thể quản lý sản phẩm và đơn hàng.

---

## 🚀 Tính Năng Chính

- **Duyệt sản phẩm**: Khám phá các sản phẩm với hình ảnh, mô tả và giá cả.
- **Giỏ hàng**: Thêm, xóa và cập nhật sản phẩm trong giỏ hàng.
- **Đăng ký & Đăng nhập**: Người dùng có thể đăng ký tài khoản và đăng nhập để theo dõi đơn hàng.
- **Quản lý sản phẩm**: Admin có thể thêm, sửa hoặc xóa sản phẩm.
- **API**: Kết nối frontend và backend qua các API RESTful.
- **Thanh toán**: Hoàn tất các bước thanh toán đơn hàng.

---

## 🔧 Kiến Trúc và Công Nghệ

- **Backend (API)**:  
  - **Laravel**: Framework PHP mạnh mẽ dùng để xây dựng API và xử lý logic backend.
  - **MySQL**: Cơ sở dữ liệu lưu trữ thông tin người dùng, sản phẩm và đơn hàng.
  - **API RESTful**: Kết nối frontend và backend bằng API JSON.

- **Frontend**:  
  - **Vue.js**: Framework JavaScript cho phép xây dựng giao diện người dùng tương tác mạnh mẽ.
  - **Axios**: Dùng để gửi yêu cầu HTTP từ frontend tới API của backend.
